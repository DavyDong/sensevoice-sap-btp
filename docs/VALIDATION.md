## 环境与测量

- 本地：Windows 11 x64，Intel Core i7-1370P，约 32 GiB RAM，Python 3.11.15，CPU 4 线程。进程及子进程观测峰值约 3.12 GiB。
- CF：6G 内存、6G disk、CPU 2 线程、1 worker。烟测后平台内存样本约 1.38–1.4 GiB、磁盘约 2.86–2.9 GiB；没有取得容器峰值，不能据此保证缩容。
- 云端 120 秒文件一次测量：推理 12.113 秒，RTF 0.101，22 段；121 秒输入返回 400。
- 最终固定 token 验证中，5.616 秒中文样例 multipart 推理约 0.689 秒；WSS 分段终点到返回约 0.898 秒，含网络与切段处理。这些是样本测量，不是 SLA。

模型/依赖版本见 README 和锁文件。ASR 输出存在样例词语差异，没有人工标注集支持的 CER/WER 或自然混说准确率结论。
